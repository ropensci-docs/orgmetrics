# Package index

## All functions

- [`clone_gh_org_repos()`](https://docs.ropensci.org/orgmetrics/reference/clone_gh_org_repos.md)
  : Clone or update all repositories defined in 'packages.json'

- [`om_packages_json()`](https://docs.ropensci.org/orgmetrics/reference/om_packages_json.md)
  : Collate and write the 'package.json' file for org

- [`orgmetrics_dashboard()`](https://docs.ropensci.org/orgmetrics/reference/orgmetrics_dashboard.md)
  :

  Start quarto dashboard with results of `orgmetrics_collate_org_data`
  function for collation of data across orgs.

- [`orgmetrics_deploy_r_univ()`](https://docs.ropensci.org/orgmetrics/reference/orgmetrics_deploy_r_univ.md)
  : Deploy a dashboard from an 'r-universe' "packages.json" file.
